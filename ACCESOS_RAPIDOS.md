# 🔗 Accesos Rápidos — Comandos y URLs

## Abrir en Navegador

### 🔐 Supabase SQL Editor (Migraciones)
**URL:** https://app.supabase.com/project/ndxyflcscxbgpelpvrtb/sql/new

**Pasos:**
1. Clic en el enlace arriba
2. Asegurar login en Supabase
3. Copiar SQL de `SUPABASE_MIGRACION_METAS.md`
4. Pegar en SQL Editor
5. Click **Run** (▶️)
